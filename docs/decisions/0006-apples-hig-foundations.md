# 0006 - Apple's HIG Foundations

- **Date:** 2026-11-13
- **Status:** Accepted

## Context

The user asked for Apple's Human Interface Guidelines to be followed, as in
their other projects. See `docs/apple-hig-review.md`.

## Decision

Text 7:1 on what it sits on; meaningful shapes 3:1; the system font; 13 px
text; controls 28 px tall; native controls throughout so Tab, Space, Return,
the arrows and screen readers work; the table steps with the arrow keys;
messages stay until something replaces them and say what to do; deleting a
profile asks first.

## Consequences

- The page can't follow Increase Contrast; it does follow the browser's zoom.
