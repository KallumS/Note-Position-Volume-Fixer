Note Position & Volume Fixer

Moves MIDI notes so a sample library's sound lands where the note was written, and evens out notes that come out too loud or too quiet. Everything happens on this computer: no file leaves it.

How to get the files out of your DAW and back in

Ableton Live

  1. Right-click the MIDI clip and choose Export MIDI Clip…
  2. Render the same clip: select it, then File › Export Audio/Video with Render Start at the clip's start, or freeze the track and drag the frozen clip to an audio track. Turn off reverb sends so each note is clear.
  3. Drop both files below, then Download Fixed MIDI and drag it into the arrangement where the clip was.

Cubase

  1. Select the part, then File › Export › MIDI Loop… (or MIDI File with only that track).
  2. File › Export › Audio Mixdown with the locators around the part, or Render in Place.
  3. Import the fixed file with File › Import › MIDI File… at the part's position.

REAPER

  1. Right-click the item and choose Export MIDI… (or glue it first).
  2. Apply track/take FX to items as new take, or render the time selection of the track.
  3. Drag the fixed file onto the track at the item's start.

Both files must start at the same moment

The audio's first sample is taken to be the MIDI file's beat 1. If the render starts somewhere else, set Audio starts late by under More Settings.
